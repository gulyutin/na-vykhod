# На выход

Статическое веб-приложение для выбора одежды перед пробежкой или подъёмом с рюкзаком на Караульную гору в Красноярске. Оно сопоставляет почасовой прогноз на время выхода с вещами, которые пользователь добавил в гардероб.

## Что умеет

- По умолчанию смотрит погоду у часовни Параскевы Пятницы — верхней точки приложенного маршрута от ГАИ на Брянской. По GPX протяжённость выхода около 2,9 км туда-обратно. Исходный GPX и временные метки в проект не включены.
- Позволяет выбрать бег или подъём с рюкзаком, время старта и продолжительность до 6 часов.
- Просит указать фактическое покрытие маршрута: сухая лестница, грунт, снег на асфальте или лёд. Прогноз не определяет, есть ли лёд на ступенях; обувь выбирается с учётом ответа.
- По явному нажатию может определить текущее местоположение или найти другой город.
- Показывает погоду на выбранное время выхода с пиктограммой и оценивает холод, осадки и ветер на весь маршрут.
- Даёт два списка: что надеть и что взять в рюкзак. Если нужной вещи нет в гардеробе, показывает это явно.
- Показывает в конце страницы каталожную сборку из иллюстраций выбранных вещей: верхний и нижний слои, обувь, головной убор и аксессуары меняются вместе с рекомендацией. Рядом перечисляет полный комплект и вещи для рюкзака.
- Подбирает одну из 12 заглавных иллюстраций маршрута по погоде и температуре, включая жару до +40 °C и мороз до −40 °C. Под иллюстрацией показывает именно выбранные алгоритмом вещи; так погодные сцены сочетаются с разными комплектами без отдельной фотографии для каждой комбинации. При экстремальной жаре или морозе советует перенести выход. На иллюстрациях показаны лестница с металлическим каркасом и деревянными перилами, часовня наверху и мост через Качу внизу города.
- Содержит стартовый список из 24 вещей владельца, включая три пары обуви, два баффа и аксессуары. Четыре куртки расположены по личной оценке теплоты: ветровка Uniqlo, мембрана Northland, софтшелл, лыжная Nordway. Джемперы расположены от менее тёплого к более тёплому: Винд, Норд, Glissade; Винд тоже флисовый и сам по себе ощутимо тёплый. Около нуля для подъёма приложение предлагает Винд первым слоем и мембрану; в более сильный холод добавляет термобельё. У джемперов Винд и Норд можно выключить свойство «Можно надевать первым слоем», если личный опыт подсказывает другую схему. Вещи показаны оригинальными иллюстрациями в едином стиле: изображения передают тип предмета и сообщённый цвет, но точный фасон может отличаться. Изменения гардероба сохраняются в браузере. Для переноса на другое устройство есть выгрузка и загрузка JSON.

Приложение работает без серверной части, сборки и ключей API. Погодные данные — [Open-Meteo](https://open-meteo.com/en/docs). Бесплатный доступ к API рассчитан на некоммерческое использование; действуют [условия и лимиты](https://open-meteo.com/en/terms). Прогноз — модельная оценка: на открытой вершине ветер может быть сильнее.

Если пользователь нажимает «Моё местоположение», координаты передаются Open-Meteo для запроса прогноза. При выборе города или Караульной горы передаются координаты выбранной точки. Стартовый список одежды входит в публичный исходный код; последующие изменения и добавленные вещи остаются в браузере и никуда не отправляются.

## Проверка локально

Из папки проекта запустите статический сервер, например `python3 -m http.server 8765`, и откройте `http://localhost:8765`. Открытие `index.html` напрямую может блокировать ES-модули в браузере.

Проверка правил подбора и выбора иллюстрации: `node --test test/*.test.mjs`.

## Публикация на GitHub Pages

Сайт опубликован: https://gulyutin.github.io/na-vykhod/. Исходный код: https://github.com/gulyutin/na-vykhod.

Сайт публикуется из корня ветки `main` через **Settings → Pages → Deploy from a branch**. GitHub Pages работает по HTTPS; это нужно для браузерной геолокации.

Инструкция основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site). Опубликованный сайт доступен всем. Начальный список одежды виден в репозитории; личные правки каждого посетителя остаются на его устройстве.

## Как настроить свои вещи

Откройте раздел «Твои вещи» и поправьте оценки теплоты, если личный опыт отличается. Для новой вещи укажите название, категорию, теплоту, защиту от ветра/дождя и вид активности. Для обуви укажите покрытия, на которых она держит сцепление. Кнопка «Загрузить примеры» добавляет отдельные демонстрационные вещи; их можно удалить кнопкой «Убрать примеры». Алгоритм — практическая эвристика для движения; он не заменяет проверку фактической погоды и собственного самочувствия.

Рекомендации по многослойной одежде и регулировке слоёв основаны на материалах [National Park Service](https://www.nps.gov/teachers/classrooms/dressing-for-winter.htm) и [CDC](https://www.cdc.gov/winter-weather/prevention/index.html).
