# На выход

Статическое веб-приложение для выбора одежды перед пробежкой или подъёмом с рюкзаком на Караульную гору в Красноярске. Оно сопоставляет почасовой прогноз на время выхода с вещами, которые пользователь добавил в гардероб.

## Что умеет

- По умолчанию смотрит погоду у часовни Параскевы Пятницы — верхней точки приложенного маршрута от ГАИ на Брянской. По GPX протяжённость выхода около 2,9 км туда-обратно. Исходный GPX и временные метки в проект не включены.
- Позволяет выбрать бег или подъём с рюкзаком, время старта и продолжительность до 6 часов.
- По явному нажатию может определить текущее местоположение или найти другой город.
- Показывает погоду сейчас и оценивает холод, осадки и ветер на всё выбранное время.
- Даёт два списка: что надеть и что взять в рюкзак. Если нужной вещи нет в гардеробе, показывает это явно.
- Сохраняет гардероб только в браузере. Для переноса на другое устройство есть выгрузка и загрузка JSON.

Приложение работает без серверной части, сборки и ключей API. Погодные данные — [Open-Meteo](https://open-meteo.com/en/docs). Бесплатный доступ к API рассчитан на некоммерческое использование; действуют [условия и лимиты](https://open-meteo.com/en/terms). Прогноз — модельная оценка: на открытой вершине ветер может быть сильнее.

Если пользователь нажимает «Моё местоположение», координаты передаются Open-Meteo для запроса прогноза. При выборе города или Караульной горы передаются координаты выбранной точки. Список одежды никуда не отправляется и хранится локально в браузере.

## Проверка локально

Из папки проекта запустите статический сервер, например `python3 -m http.server 8765`, и откройте `http://localhost:8765`. Открытие `index.html` напрямую может блокировать ES-модули в браузере.

Проверка правил подбора: `node --test test/logic.test.mjs`.

## Публикация на GitHub Pages

1. Создайте новый **публичный** репозиторий GitHub и загрузите в его корень `index.html`, `styles.css`, `app.js`, `logic.mjs` и `.nojekyll`. `README.md` и `test/` можно добавить для сохранения исходников.
2. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
3. Дождитесь адреса Pages в том же разделе. GitHub Pages работает по HTTPS; это нужно для браузерной геолокации.

Инструкция основана на [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site). Опубликованный сайт доступен всем. Гардероб остаётся на устройстве посетителя и не попадает в репозиторий.

## Как настроить свои вещи

Откройте раздел «Твои вещи» и добавьте название, категорию, теплоту, защиту от ветра/дождя и вид активности. Кнопка «Загрузить примеры» добавляет только демонстрационные названия: замените их на свою одежду перед использованием или удалите кнопкой «Убрать примеры». Алгоритм — практическая эвристика для движения; он не заменяет проверку фактической погоды и собственного самочувствия.

Рекомендации по многослойной одежде и регулировке слоёв основаны на материалах [National Park Service](https://www.nps.gov/teachers/classrooms/dressing-for-winter.htm) и [CDC](https://www.cdc.gov/winter-weather/prevention/index.html).
